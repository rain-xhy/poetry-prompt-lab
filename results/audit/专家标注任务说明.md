# 古诗词英译语义核对：专家标注任务说明

## 一 背景

我们在研究提示词的写法如何影响小型语言模型翻译古诗词时的语义保留。模型已经为一批诗词生成了英文译文。为了比较不同提示词的效果，我们让另一个模型（下称自动评审器）逐项检查译文有没有保住原诗的关键语义。这个自动评审器本身是否可靠，需要由人来检验。

您的工作是对一批抽样出来的检查项作出判断。您的判断会与自动评审器的判断逐项对照，用来计算两者的一致程度。请完全按照您自己的专业判断填写，不要去猜自动评审器会怎么判。

## 二 您会收到的文件

一个表格文件 audit_sheet_expert.csv，共 179 行，每行是一项检查，可以用 Excel 或 WPS 打开。各列含义如下。

| 列 | 内容 |
|---|---|
| item 题号 | 每行的编号，请勿修改 |
| original_poem 原诗全文 | 被翻译的中文诗词全文，诗行之间用斜杠隔开 |
| original_phrase 本行检查的原句 | 这一行只检查这一句或这一个要点 |
| must_preserve 需要保住的意思 | 这一句的译文应当保住的语义 |
| pass_conditions 判定条件 | 判定通过的具体条件，有多条时须全部满足 |
| translation 模型译文 | 模型给出的整首英文译文，各行之间用斜杠隔开 |
| human_pass 您的判断 | 请填写 1 或 0 |
| note 备注 | 选填 |

## 三 每一行怎么做

先读原诗全文，了解整首诗的意思。再看本行要检查的原句、需要保住的意思和判定条件。然后在译文里找出对应这一句的英文，判断它是否满足判定条件。满足填 1，不满足填 0。判断时请遵循下面几条。

1. 以意思为准，不以措辞为准。同义说法、调整语序、合理的意译，只要保住了要求的意思，都算满足。
2. 判定条件有多条时，必须全部满足才填 1。只满足其中一部分，填 0。
3. 只判断本行这一个要点，不评价整首译文的优劣，也不评价英文是否优美。译文别处的错误，不影响本行的判断。
4. 不给半分。拿不准时，请想象一位不懂中文、只读这段英文的读者，看他能否从中得到所要求的意思。能则填 1，不能则填 0。
5. 意思被颠倒的一律填 0。常见的有否定变肯定，施事与受事互换，将来变过去，假设变事实，条件变因果。
6. 译文把原诗中的词原样留成了中文字符时，同样按第 4 条判断。如果所要求的意思必须靠那个中文字才能看懂，填 0。
7. 译文里没有对应这一句的内容，或者与原句无关，填 0。
8. 括号里的注释和以 Note 开头的注释已经从译文中去掉，您看到的就是正文，不用考虑注释。

个别题目中的原诗是我们为测试而改写过的版本，例如改动了某个字，使主语或逻辑关系与名篇不同。请以表中原诗全文的文字和判定条件为准，不要按您记忆中的名篇原句去判断。

## 四 示例

以下例子取自一首不在表中的诗，李清照《一剪梅》的片段“此情无计可消除，才下眉头，却上心头”，只用来说明判断标准。

| 本行检查的原句与要点 | 译文片段 | 填写 | 理由 |
|---|---|---|---|
| 此情无计可消除，愁绪无法排遣，否定方向要正确 | there is no way to be rid of this longing | 1 | 表达了无法排遣 |
| 同上 | this feeling is gone | 0 | 否定被颠倒成了已经消除 |
| 同上 | I do not want to remove it | 0 | 把无法改成了不愿 |
| 才下眉头，愁刚刚从眉间离开 | it has just left my brow | 1 | 时间和方向都对 |
| 同上 | it stays on my brow | 0 | 方向相反 |
| 才下……却上，愁在眉与心之间紧接着转移，读者能感到愁没有消失 | no sooner gone from my brow than it lodges in my heart | 1 | 前后紧接，愁仍然存在 |
| 同上 | it leaves my brow. it is in my heart. | 0 | 两句各自成立，看不出接续 |


## 六 填写与交回

human_pass 一列只填半角数字 1 或 0，不要写其他内容，留空的行会被当作没有判断。拿不准的行，也请给出 1 或 0，同时可以在 note 列写一句理由。
